# Weather4Lox JSON Schema v1.0

This document is the authoritative reference for the JSON files produced by Weather4Lox grabbers.
All JSON output is generated by `bin/grabber_utils.pl` (`writeJsonFile`).

---

## Envelope Structure

Every JSON file shares the same top-level envelope with source-specific metadata:

```json
{
  "location": { ... },
  "<grabberKey>": { ... },
  "<weatherKey>": ...
}
```

- `location` -- object; always present, contains geographic information about the observation site
- `<grabberKey>` -- one or more source-specific metadata objects (e.g. `"wetteronline"`, `"wunderground"`)
- `<weatherKey>` -- `"current"` (object), `"dailyforecast"` (array), or `"hourlyforecast"` (array)

### location Fields

| Field        | Type   | Description                                          |
|--------------|--------|------------------------------------------------------|
| `city`       | string | Observation location city name                       |
| `country`    | string | Country name                                         |
| `countryCode`| string | ISO 3166-1 alpha-2 country code, e.g. `"DE"`        |
| `elevation`  | number | Elevation above sea level (m)                        |
| `latitude`   | number | Geographic latitude                                  |
| `longitude`  | number | Geographic longitude                                 |
| `timezone`   | string | IANA timezone name, e.g. `"Europe/Berlin"`           |
| `tzOffset`   | string | UTC offset, e.g. `"+0100"`                           |
| `tzShort`    | string | Timezone abbreviation, e.g. `"CET"`                  |

### Grabber Metadata Fields

Each grabber writes its own metadata section using its key (e.g. `"wetteronline"`, `"wunderground"`).

| Field          | Type   | Description                                                  |
|----------------|--------|--------------------------------------------------------------|
| `filename`     | string | Absolute path to the output file on the LoxBerry system      |
| `generatedAt`  | string | ISO 8601 timestamp (without offset) when the grabber ran     |
| `grabberLabel` | string | Human-readable name of the data provider                     |
| `grabberScript`| string | Grabber filename, e.g. `"grabber_wetteronline.pl"`           |
| `schemaVersion`| string | Schema version: `"v1.0"`                                     |
| `observedAt`   | string\|null | Observation timestamp from the source (optional)        |
| `stationID`    | string\|null | Weather station identifier (optional, e.g. WU)          |

## current.json

`current` is a single object representing the most recent observation.

### Envelope Example

```json
{
  "current": { ... },
  "location": { ... },
  "wetteronline": { "filename": "...", "generatedAt": "...", ... },
  "wunderground": { "filename": "...", "generatedAt": "...", ... }
}
```

### current -- Top-level Fields

| Field            | Type         | Unit  | Description                              |
|------------------|--------------|-------|------------------------------------------|
| `cloudCover`     | number       | %     | Cloud cover                              |
| `dewpoint`       | number       | C     | Dew point temperature                    |
| `humidity`       | number       | %     | Relative humidity                        |
| `isNight`        | integer      | --    | 1 = nighttime, 0 = daytime              |
| `moon`           | object       | --    | Moon data (see below)                    |
| `ozone`          | number\|null | DU    | Total ozone column (Dobson Units)        |
| `precipitation`  | object       | --    | Precipitation data (see below)           |
| `pressure`       | number       | mbar  | Atmospheric pressure                     |
| `solarRadiation` | number\|null | W/m2  | Solar radiation                          |
| `sunrise`        | string       | --    | Sunrise time as `"HH:MM"` local time    |
| `sunset`         | string       | --    | Sunset time as `"HH:MM"` local time     |
| `temperature`    | object       | --    | Temperature data (see below)             |
| `time`           | object       | --    | Time data (see below)                    |
| `uvIndex`        | number       | --    | UV index                                 |
| `visibility`     | number\|null | m     | Horizontal visibility in meters          |
| `weatherCode`    | object       | --    | Weather condition data (see below)       |
| `wind`           | object       | --    | Wind data (see below)                    |

### current.moon

| Field       | Type   | Unit | Description                                    |
|-------------|--------|------|------------------------------------------------|
| `age`       | number | d    | Age of the moon in days                        |
| `direction` | string | --   | `"waxing"` or `"waning"`                       |
| `percent`   | number | %    | Moon illumination percentage                   |
| `phase`     | number | %    | Moon phase (0--100)                            |

### current.precipitation

| Field         | Type         | Unit | Description                              |
|---------------|--------------|------|------------------------------------------|
| `probability` | number       | %    | Probability of precipitation             |
| `rain1hr`     | number       | mm   | Precipitation in the last hour           |
| `rainToday`   | number       | mm   | Total precipitation today                |
| `snow1h`      | number\|null | cm   | Snow in the last hour                    |
| `snowToday`   | number\|null | cm   | Total snow today                         |
| `type`        | string       | --   | Precipitation type: `"none"`, `"rain"`, `"snow"`, `"mixed"` |

### current.temperature

| Field      | Type   | Unit | Description                        |
|------------|--------|------|------------------------------------|
| `air`      | number | C    | Current air temperature            |
| `feelsLike`| number | C    | Apparent ("feels like") temperature|
| `heatIndex`| number | C    | Heat index                         |
| `windChill`| number | C    | Wind chill temperature             |

### current.time

| Field      | Type    | Description                                                |
|------------|---------|-------------------------------------------------------------|
| `datetime` | string  | ISO 8601 observation timestamp, e.g. `"2026-03-24T20:40:24+01:00"` |
| `epoch`    | integer | Unix epoch of the observation (seconds)                    |
| `timezone` | string  | IANA timezone name, e.g. `"Europe/Berlin"`                 |
| `tzOffset` | string  | UTC offset, e.g. `"+0100"`                                 |
| `tzShort`  | string  | Timezone abbreviation, e.g. `"CET"`                        |

### current.weatherCode

| Field         | Type   | Description                                              |
|---------------|--------|----------------------------------------------------------|
| `description` | string | Human-readable weather description (localized)           |
| `image`       | string | Icon filename (with day/night suffix), e.g. `"overcast_night"` |
| `loxone`      | string | Loxone weather code for Miniserver                       |
| `metar`       | string | METAR sky condition code, e.g. `"OVC"`, `"BKN"`, `"SCT"`|
| `weather4lox` | string | Weather4Lox internal identifier, e.g. `"overcast"`       |

### current.wind

| Field      | Type         | Unit | Description                                |
|------------|--------------|------|--------------------------------------------|
| `dirLabel` | string       | --   | Wind direction as label, e.g. `"Sued-Westen"` |
| `direction`| number       | deg  | Wind direction in degrees (0--360)         |
| `gust`     | number       | km/h | Wind gust speed                            |
| `speed`    | number       | km/h | Wind speed                                 |

## Field Conventions

- **camelCase** for all field names (e.g. `cloudCover`, `feelsLike`, `dirLabel`)
- Missing values: JSON `null` (not omitted, not empty string, not 0 or -9999)
- `day` field in dailyforecast: 0-based index (0 = today, 1 = tomorrow, ...)
- `hour` field in hourlyforecast: 0-based index (0 = first hour, 1 = +1 hour, ...)
- `datetime`: ISO 8601 with timezone offset (e.g. `"2026-03-24T20:40:24+01:00"`)
- `epoch`: Unix timestamp (seconds since 1970-01-01)
- `generatedAt` in grabber metadata: ISO 8601 without offset (local system time)
- Nested objects group related fields: `temperature`, `wind`, `precipitation`, `moon`, `time`, `weatherCode`
- `weatherCode.weather4lox`: normalized identifier used for icon mapping
- `weatherCode.image`: includes `_day`/`_night` suffix in current.json, `null` in daily forecasts
- `weatherCode.loxone`: string (not integer) -- Loxone weather code

## Encoding

- UTF-8 via `JSON::PP->new->pretty->canonical->utf8` with `open '>:raw'`
- Decimal numbers: dot separator (locale-independent via JSON::PP + `$v + 0` coercion)
- **Never** combine `JSON::PP->utf8` with `'>:encoding(UTF-8)'` (double-encoding)
