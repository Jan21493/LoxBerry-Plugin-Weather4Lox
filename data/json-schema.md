# Weather4Lox JSON Schema v1.0

This document is the authoritative reference for the JSON files produced by Weather4Lox grabbers.
All JSON output is generated by `bin/grabber_utils.pl` (`write_current_json`, `write_daily_json`,
`write_hourly_json`, `write_current_json_aq`).

---

## Envelope Structure

Every JSON file shares the same top-level envelope:

```json
{
  "meta": { ... },
  "data": ...
}
```

- `meta` — object; always present, contains schema metadata
- `data` — object (current.json) or array of objects (dailyforecast.json, hourlyforecast.json)

---

## meta Fields

| Field            | Type   | Description                                                                 |
|------------------|--------|-----------------------------------------------------------------------------|
| `schema_version` | string | Schema version: `"1.0"`                                                     |
| `source`         | string | Data provider name, e.g. `"OpenWeatherMap"`, `"VisualCrossing"`, `"wttr.in"` |
| `grabber`        | string | Grabber filename, e.g. `"grabber_openweather.pl"`                           |
| `generated_at`   | string | ISO 8601 timestamp (with timezone offset) when the grabber ran, e.g. `"2026-03-12T21:00:00+01:00"` |

## current.json

`data` is a single object representing the most recent observation.

### current.json — data fields

| Field                  | Type          | Unit    | Description                                                                          |
|------------------------|---------------|---------|--------------------------------------------------------------------------------------|
| `datetime`             | string        | —       | ISO 8601 observation timestamp (from epoch + timezone), e.g. `"2026-03-12T20:45:00+01:00"` |
| `epoch`                | integer       | s       | Unix epoch of the observation                                                        |
| `timezone`             | string        | —       | IANA timezone name, e.g. `"Europe/Berlin"` (from .dat tz_long)                      |
| `city`                 | string        | —       | Observation location city name                                                       |
| `country`              | string        | —       | Country name                                                                         |
| `country_code`         | string        | —       | ISO 3166-1 alpha-2 country code, e.g. `"DE"`                                        |
| `latitude`             | number        | °       | Geographic latitude                                                                  |
| `longitude`            | number        | °       | Geographic longitude                                                                 |
| `elevation`            | number        | m       | Elevation above sea level                                                            |
| `temperature`          | number        | °C      | Current air temperature                                                              |
| `feelslike`            | number        | °C      | Apparent ("feels like") temperature                                                  |
| `humidity`             | number        | %       | Relative humidity                                                                    |
| `wind_direction_desc`  | string        | —       | Wind direction as cardinal/intercardinal label, e.g. `"NW"`                         |
| `wind_direction_deg`   | number        | °       | Wind direction in degrees (0–360)                                                    |
| `wind_speed`           | number        | km/h    | Wind speed                                                                           |
| `wind_gust`            | number        | km/h    | Wind gust speed                                                                      |
| `windchill`            | number        | °C      | Wind chill temperature                                                               |
| `pressure`             | number        | mbar    | Atmospheric pressure                                                                 |
| `dewpoint`             | number        | °C      | Dew point temperature                                                                |
| `visibility`           | number        | km      | Horizontal visibility                                                                |
| `solar_radiation`      | number        | W/m²    | Solar radiation                                                                      |
| `heat_index`           | number        | °C      | Heat index                                                                           |
| `uv_index`             | number        | —       | UV index                                                                             |
| `precip_today_mm`      | number        | mm      | Total precipitation today                                                            |
| `precip_1hr_mm`        | number        | mm      | Precipitation in the last hour                                                       |
| `weather_icon`         | string        | —       | Icon filename (without extension), e.g. `"partly-cloudy"`                           |
| `weather_code`         | integer       | —       | Weather4Lox legacy weather code (see data/weathercodes.json)                        |
| `weather_id`           | string        | —       | Normalized weather identifier derived from `weather_code`, e.g. `"partly-cloudy"` (null if code not mapped) |
| `weather_description`  | string        | —       | Human-readable weather description                                                   |
| `moon_percent`         | number        | %       | Moon illumination percentage                                                         |
| `moon_age`             | number        | d       | Age of the moon in days                                                              |
| `moon_phase`           | number        | %       | Moon phase (0–100)                                                                   |
| `moon_hemisphere`      | string        | —       | Hemisphere for moon phase display, e.g. `"north"` or `"south"`                      |
| `sunrise`              | string        | —       | Sunrise time as `"HH:MM"` in local time                                              |
| `sunset`               | string        | —       | Sunset time as `"HH:MM"` in local time                                               |
| `ozone`                | number        | DU      | Total ozone column (Dobson Units)                                                    |
| `cloud_cover`          | number        | %       | Cloud cover                                                                          |
| `precip_probability`   | number        | %       | Probability of precipitation                                                         |
| `snow`                 | number        | cm      | Snow depth or snow forecast                                                          |
| `aqi_eu`               | number\|null  | —       | European Air Quality Index (1–5); null unless set by OpenMeteo AQ grabber           |
| `aqi_us`               | number\|null  | —       | US Air Quality Index (1–6); null unless set by OpenMeteo AQ grabber                 |
| `pm10`                 | number\|null  | µg/m³   | PM10 particulate matter; null unless set by OpenMeteo AQ grabber                    |
| `pm25`                 | number\|null  | µg/m³   | PM2.5 particulate matter; null unless set by OpenMeteo AQ grabber                   |
| `pollen_alder`         | number\|null  | grains/m³ | Alder pollen concentration; null unless set by OpenMeteo AQ grabber               |
| `pollen_birch`         | number\|null  | grains/m³ | Birch pollen concentration; null unless set by OpenMeteo AQ grabber               |
| `pollen_grass`         | number\|null  | grains/m³ | Grass pollen concentration; null unless set by OpenMeteo AQ grabber               |
| `pollen_mugwort`       | number\|null  | grains/m³ | Mugwort pollen concentration; null unless set by OpenMeteo AQ grabber             |
| `pollen_olive`         | number\|null  | grains/m³ | Olive pollen concentration; null unless set by OpenMeteo AQ grabber               |
| `pollen_ragweed`       | number\|null  | grains/m³ | Ragweed pollen concentration; null unless set by OpenMeteo AQ grabber             |
| `pollen_overall_today` | number\|null  | —       | Overall pollen level today (index); null unless set by OpenMeteo AQ grabber         |
| `pollen_overall_tomorrow` | number\|null | —    | Overall pollen level tomorrow (index); null unless set by OpenMeteo AQ grabber      |

## Notes

### hourlyhistory.json

Not yet defined in v1.0. Reserved for a future schema version.

### Encoding and Conventions

- All JSON files are encoded as **UTF-8** (written with `:raw` and `JSON::PP->utf8`)
- Decimal numbers use **decimal points** (never commas), per JSON standard
- **null** is used for missing or unavailable values (not `""` or `0`)
- Numeric strings from .dat files are auto-converted to numbers by the `_val()` helper
- Empty string in .dat becomes `null` in JSON

### Atomic Write Guarantee

All JSON files are written atomically using a `.tmp` file:

1. Write to `{output}.tmp`
2. `File::Copy::move()` renames `.tmp` to final path

This matches the existing `.dat` write pattern. A reader will never see a partial JSON file.

### AQ Fields

AQ fields (`aqi_eu`, `aqi_us`, `pm10`, `pm25`, `pollen_*`) are always present in `current.json`
but default to `null`. They are populated only when `write_current_json_aq()` is called by the
OpenMeteo AQ supplementary grabber.

### weather_id Normalization

`weather_id` is derived from `weather_code` via a static mapping table in `grabber_utils.pl`
(see `%WEATHER_CODE_TO_ID`). If the code has no mapping entry, `weather_id` is absent from the
output. Consumers should treat `weather_id` as optional/nullable.

### schema_version

The current schema version is `"1.0"`. This field allows consumers to detect breaking changes
in future schema versions.
